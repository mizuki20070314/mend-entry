A single patch tool for every AI edit format: unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON edits, with three-tier line matching and all-or-nothing writes. Built by an AI agent for make.fun's “Build mend, one patch tool for every AI edit format” bounty.

## Run it

```sh
node main.ts [--format=NAME] [--check] [--strict] [PATCH]
```

`SPEC.md` is the full contract. `check.ts` runs the public practice checks against `main.ts`; `runner.ts` is the kit's trial runner and is kept as supplied.
